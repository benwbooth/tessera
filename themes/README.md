# Bundled color themes

`iterm2-color-schemes.json` holds the schemes from
[mbadolato/iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
whose licences allow redistribution under permissive terms (MIT, Apache-2.0,
ISC, CC0, WTFPL and similar), converted from the repository's Ghostty files.
Each entry keeps its `license`. The repository's own licence is in
`iterm2-color-schemes.LICENSE`.

Schemes with unknown, copyleft or non-free licences are not bundled.
Preferences › Profiles › Colors › "Get All iTerm2-Color-Schemes" downloads
the complete collection into your own settings folder instead.
